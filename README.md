# Fassadenplaner

Windows-Standalone-Anwendung auf Basis von C# / WPF.

## Geplante Funktionen

- Plattenstamm / Materialhistorie
- Fassadenfläche mit Öffnungen
- Live-Raster
- Hochformat / Querformat / dynamische Ausrichtung
- Optimierung nach Optik oder Verschnitt
- manuelles Verschieben der Aufteilung
- 3D-Visualisierung
- Plattenbedarf
- Zuschnittplan
- PDF-Ausgabe

## Windows Installer

Der GitHub-Workflow **Windows Installer** erzeugt eine selbstständige win-x64 Anwendung und einen Inno-Setup-Installer.

Aktueller Projektstand: Grundgerüst.
